One month, great experience, started with a company meeting to provide all the information needed and tasks, and a scheduled meeting every week for updates and feedback. 
The first week's task was to understand the three datasets provided, perform an EDA (Exploratory Data Analysis), and then clean them using Python.
The second week's task was to upload data to PostgreSQL, perform query checks, and create a master table, then connect to Looker Studio through Supabase, and make a dashboard.
The third week's task was to do data validation and consistency checks using SQL queries and come up with key insights.
The fourth and last week's task was to come up with actionable recommendations and prepare a final presentation.
I learned new skills like PostgreSQL, Looker Studio, and communication, where I had 4 other foreign teammates and communicated in English, verbal and written.<img
